# 藤澤市 このまちアーカイブス 江の島

## 擷取內容
- 江之島是與陸地相連的島：退潮時可徒步，滿潮時需要渡船；1949 年建成混凝土的江の島弁天橋，1962 年建成車輛專用的江ノ島大橋
- 岩屋是海蝕洞，因隆起現在位於海面之上；島的西南端有稚児ヶ淵的波蝕台，關東大地震時隆起約 1 公尺
- 信仰起源：古墳時代，欽明天皇敕命在岩屋祭神；1182 年源賴朝造八臂弁財天；江戶時代成為藝能、音樂、智慧之神，江戶中期起也廣傳於庶民
- 三宮（岩屋本宮、上之宮、下之宮）在明治初期神佛分離後成為江島神社，分別稱為奥津宮、中津宮、辺津宮；辺津宮祭祀八臂弁財天與妙音弁財天
