# iko-yo 江の島シーキャンドル

## 擷取內容
- 住所：神奈川縣藤澤市江の島 2-3-28（江の島サムエル・コッキング苑內）
- 2003 年重新整修的展望設施；展望室可眺望富士山、大島、三浦半島、橫濱 Landmark Tower、東京晴空塔
- 夕陽是看點；冬季是「湘南の宝石」燈飾主會場
- 展望室正下方有木製平台「THE SUNSET TERRASE」

## 限制
頁面沒有提到從塔上看得到江之島本身。
